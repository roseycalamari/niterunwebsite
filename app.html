How to Use NiteRun

Two ways to use it. A quick game for right now. Official for proper groups.

Quick game (not saved)

Perfect when you just want teams, fast.

1) Add players Names + skill level + position.
2) Generate teams Balanced in seconds.
No database saving No @ accounts, no invites, no MVP, no saved history. Just nicknames and teams.

Official Groups (Saved)

Weekly games with the full package: saved history, live profile stats, MVP tracking, and progress toward milestones and rewards.

1) Create or join a group Use an invite code, or start your own.
2) Invite your squad Share the group code so everyone can join (they need an account).
3) Verify the group (10 members) When 10 members have verified emails, the group becomes official: saved games update profile stats live.
4) Save official sessions Admins can save sessions and award MVP. Each saved game updates profiles and counts toward milestones.
